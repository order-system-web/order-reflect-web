# 受注反映アプリ（画面）

業務用ウェブアプリの**画面だけ**を置いています。

- 受注データ・顧客情報・各種IDは含まれていません
- 処理はすべて別のサーバ（Google Apps Script）で行います
- 接続先は、管理者が端末ごとに設定します。このリポジトリには入っていません
- 利用には合言葉が必要です

## 管理者向け：端末の設定手順

1. 端末のブラウザで次を開く（`<接続先>` は Apps Script のウェブアプリURL）

   ```
   https://<このページのURL>/#api=<接続先>
   ```

2. 合言葉を入力して「開く」
3. ブラウザの共有メニューから「ホーム画面に追加」
4. 以降はアイコンから開くだけで使えます

接続先はアドレス欄から自動で消え、端末の中に保存されます。
